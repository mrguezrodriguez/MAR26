01 — Fundamentos

Árboles de Decisión

Un árbol de decisión divide el espacio de features en regiones rectangulares mediante preguntas binarias sucesivas. Cada nodo interno hace una pregunta sobre un feature; cada hoja asigna una clase (clasificación) o un valor (regresión).

🌳 Terminología
TérminoQué es
RaízNodo inicial, todo el dataset
Nodo internoPregunta sobre un feature
HojaPredicción final
ProfundidadNº de splits desde raíz a hoja
RamaCamino entre nodos
⚙️ Algoritmo CART

El algoritmo de sklearn. Para cada nodo:

  1. Prueba todos los features y umbrales posibles
  2. Elige el split que minimiza la impureza de los hijos
  3. Repite recursivamente en cada subconjunto
  4. Para cuando se cumple criterio de parada (max_depth, etc.)
02 — Matemáticas

Criterios de División

🎯 Impureza de Gini (clasificación)

Mide la probabilidad de clasificar incorrectamente un elemento si lo etiquetamos al azar. 0 = nodo puro; 0.5 = máximo desorden (2 clases iguales).

Gini de un nodo
Gini(t) = 1 − Σ pᵢ²
donde pᵢ es la proporción de la clase i en el nodo t
Ejemplo: nodo con 80% positivos / 20% negativos
Gini = 1 − (0.8² + 0.2²) = 1 − (0.64 + 0.04) = 0.32
Nodo impuro → ganamos dividiendo. Si fuera una sola clase: Gini = 1 − 1² = 0 (puro)
Ganancia de Gini al hacer un split
ΔGini = Gini(padre) − [Nₗ/N · Gini(izq) + Nᵣ/N · Gini(der)]
Se elige el split que maximiza ΔGini. N = total muestras del nodo padre; Nₗ, Nᵣ = muestras en cada hijo

📊 Entropía e Information Gain

Viene de la teoría de la información (Shannon). Alternativa a Gini; usa criterion="entropy".

Entropía de un nodo
H(t) = −Σ pᵢ · log₂(pᵢ)
Si pᵢ = 0 → 0·log(0) = 0 por convenio. Máximo: H = log₂(K) para K clases equiprobables
Information Gain
IG = H(padre) − [Nₗ/N · H(izq) + Nᵣ/N · H(der)]
Mismo criterio que ID3/C4.5. Se maximiza el IG para elegir el mejor split.
ℹ️
Gini vs Entropía: resultados muy similares en práctica. Gini es más ligero computacionalmente (sin logaritmos). sklearn usa Gini por defecto.

📉 MSE para Regresión

MSE de un nodo (criterio de regresión)
MSE(t) = (1/N) · Σ (yᵢ − ȳ)²
La predicción de la hoja es la media ȳ de los valores en ese nodo

🛑 Hiperparámetros de poda (pre-pruning)

max_depth

Profundidad máxima. Sin límite → memoriza training set. Típico: 3–10.

min_samples_split

Nº mínimo de muestras para dividir un nodo. Por defecto: 2.

min_samples_leaf

Nº mínimo de muestras en cada hoja tras el split.

max_features

Nº máximo de features a considerar en cada split. Clave en Random Forest.

03 — Ensemble paralelo

Bagging

Bagging = Bootstrap Aggregating. Entrenas muchos modelos independientes sobre subconjuntos aleatorios (con reemplazo) del dataset, y combinas sus predicciones.

🧮 ¿Por qué funciona? Bias-Variance

Descomposición del error
Error = Bias² + Variance + Ruido irreducible
Los árboles profundos tienen bajo Bias pero alta Variance. Bagging reduce la Variance sin aumentar el Bias.
Reducción de varianza al promediar B modelos
Var(ȳ) = σ²/B (si modelos son independientes)
En la práctica la correlación entre modelos limita la reducción. Por eso RF introduce aleatoriedad extra en features.
Predicción final — clasificación (voto)
ŷ = argmax_c Σᵦ 𝟙[hᵦ(x) = c]
Regresión: ŷ = (1/B) · Σᵦ hᵦ(x)

💻 BaggingClassifier

from sklearn.ensemble import BaggingClassifier
from sklearn.tree import DecisionTreeClassifier

bagging = BaggingClassifier(
    estimator=DecisionTreeClassifier(max_depth=5),
    n_estimators=100,   # número de árboles
    max_samples=1.0,    # fracción del dataset por bootstrap
    max_features=1.0,   # fracción de features
    bootstrap=True,      # con reemplazo (bootstrap)
    random_state=42,
    n_jobs=-1
)
bagging.fit(X_train, y_train)
print(bagging.score(X_test, y_test))
04 — Bagging con aleatoriedad doble

Random Forest

Random Forest = Bagging + en cada split se selecciona un subconjunto aleatorio de features. Esto descorrelaciona los árboles → mayor reducción de varianza.

⚡
La clave: si un feature es muy dominante, todos los árboles lo elegirán → alta correlación entre árboles → Bagging no reduce mucho la varianza. RF fuerza a ignorar algunos features en cada split → mayor diversidad → mejor ensemble.
Número de features por split (regla empírica)
Clasificación: max_features = √p
Regresión: max_features = p/3
p = número total de features. sklearn: max_features="sqrt" o "log2"
Out-of-Bag Error (OOB) — validación gratis
P(muestra no usada en un bootstrap) = (1 − 1/N)ᴺ → 1/e ≈ 36.8%
OOB_score = proporción de muestras correctamente predichas por sus OOB árboles
Cada muestra es testeada por los árboles que no la vieron → estimación de generalización sin CV extra
Feature Importance (Mean Decrease in Impurity)
Importance(fⱼ) = (1/B) · Σᵦ Σₙₒdₑₛ ΔGiniₙ · 𝟙[split en fⱼ]
Promedia la reducción de Gini atribuida a cada feature sobre todos los árboles. Ojo: sesgada hacia alta cardinalidad.

💻 Random Forest + GridSearch

from sklearn.ensemble import RandomForestClassifier

                       param_rf, cv=5, scoring='roc_auc', n_jobs=-1)

05 — Ensemble secuencial

Boosting

A diferencia de Bagging (paralelo), Boosting entrena modelos en secuencia: cada modelo se enfoca en los errores del anterior. Los modelos se combinan con pesos, no con voto igualitario.

🧮 AdaBoost — Matemáticas paso a paso

1. Error ponderado del clasificador m
εₘ = Σᵢ wᵢ · 𝟙[hₘ(xᵢ) ≠ yᵢ] / Σᵢ wᵢ
Fracción ponderada de errores. Si εₘ > 0.5: peor que el azar, se invierte el clasificador.
2. Peso del clasificador m (cuánto vale su voto)
αₘ = 0.5 · ln((1 − εₘ) / εₘ)
εₘ → 0 (casi perfecto): αₘ → ∞ | εₘ = 0.5 (azar): αₘ = 0
3. Actualización de pesos de las muestras
wᵢ ← wᵢ · exp(αₘ · 𝟙[hₘ(xᵢ) ≠ yᵢ])
Ejemplos mal clasificados reciben más peso → el siguiente modelo se fija más en ellos. Luego se normalizan (Σwᵢ = 1).
4. Predicción final
H(x) = sign( Σₘ αₘ · hₘ(x) )
Suma ponderada de clasificadores débiles. Multiclase: versión SAMME.

📉 Gradient Boosting — Matemáticas

En vez de ponderar muestras, ajusta cada modelo sobre los residuos = gradiente negativo de la función de pérdida.

Algoritmo general
F₀(x) = argmin_γ Σᵢ L(yᵢ, γ) ← predicción constante inicial
rᵢₘ = −∂L(yᵢ, Fₘ₋₁(xᵢ)) / ∂Fₘ₋₁ ← pseudoresiduos
hₘ ← árbol ajustado sobre {(xᵢ, rᵢₘ)}
Fₘ(x) = Fₘ₋₁(x) + η · hₘ(x) ← η = learning rate
Descenso de gradiente en el espacio funcional. η pequeño → más robusto, necesita más árboles.
MSE — regresión
L = (y − F(x))² / 2
Pseudoresiduos = yᵢ − Fₘ₋₁(xᵢ). Son exactamente el error.
Log-loss — clasificación
L = −y·log(p) − (1−y)·log(1−p)
Pseudoresiduos = yᵢ − p̂ᵢ (clase real − probabilidad predicha).

💻 AdaBoost y GradientBoosting

from sklearn.ensemble import AdaBoostClassifier, GradientBoostingClassifier

# AdaBoost — clasificador débil habitual: stump (max_depth=1)
ada = AdaBoostClassifier(
    estimator=DecisionTreeClassifier(max_depth=1),
    n_estimators=200,
    learning_rate=0.5,
    random_state=42
)
ada.fit(X_train, y_train)

# Gradient Boosting sklearn
gb = GradientBoostingClassifier(
    n_estimators=200,
    learning_rate=0.05,  # η pequeño → más árboles, mejor resultado
    max_depth=3,          # árbol débil típico
    subsample=0.8,        # Stochastic GB: fracción de filas
    min_samples_leaf=4,
    random_state=42
)
gb.fit(X_train, y_train)
06 — Boosting industrial

XGBoost & LightGBM

XGBoost (eXtreme Gradient Boosting) añade regularización L1/L2 nativa y usa la expansión de Taylor de 2º orden para derivar analíticamente el valor de cada hoja. LightGBM crece el árbol hoja a hoja en vez de nivel a nivel.

Función objetivo XGBoost (paso m)
Obj = Σᵢ L(yᵢ, ŷᵢ) + Σₖ Ω(fₖ)
Ω(f) = γT + (λ/2)·Σⱼ wⱼ²
T = nº hojas; wⱼ = predicción en hoja j; γ = penalización por crear hojas; λ = regularización L2
Expansión de Taylor 2º orden
L ≈ Σᵢ [gᵢ · fₘ(xᵢ) + (1/2) · hᵢ · fₘ(xᵢ)²]
gᵢ = ∂L/∂ŷᵢ (gradiente) hᵢ = ∂²L/∂ŷᵢ² (hessiano)
Permite derivar el valor óptimo de cada hoja en forma cerrada.
Valor óptimo de hoja j y criterio de ganancia del split
wⱼ* = −(Σᵢ∈Iⱼ gᵢ) / (Σᵢ∈Iⱼ hᵢ + λ)
Gain = ½ · [Gₗ²/(Hₗ+λ) + Gᵣ²/(Hᵣ+λ) − (Gₗ+Gᵣ)²/(Hₗ+Hᵣ+λ)] − γ
Split solo se realiza si Gain > 0. γ controla cuándo "vale la pena" crear una hoja nueva.

💻 XGBoost y LightGBM

import xgboost as xgb
import lightgbm as lgb

# XGBoost
xgb_model = xgb.XGBClassifier(
    n_estimators=300,
    learning_rate=0.05,
    max_depth=4,
    subsample=0.8,         # fracción de filas por árbol
    colsample_bytree=0.8,   # fracción de features por árbol
    gamma=0.1,              # penalización por hojas (γ)
    reg_lambda=1.0,         # regularización L2 (λ)
    eval_metric='auc',
    random_state=42
)
xgb_model.fit(X_train, y_train,
              eval_set=[(X_test, y_test)],   # monitorizar overfitting
              verbose=False)

# LightGBM — más rápido en datasets grandes
lgb_model = lgb.LGBMClassifier(
    n_estimators=300,
    learning_rate=0.05,
    num_leaves=31,          # controla complejidad (no max_depth)
    subsample=0.8,
    colsample_bytree=0.8,
    random_state=42
)
lgb_model.fit(X_train, y_train)

LightGBM — diferencia clave

Crece el árbol hoja a hoja (leaf-wise) en vez de nivel a nivel (level-wise). Mayor precisión con menos hojas, pero más propenso a overfitting en datos pequeños.

num_leaves = control principal de complejidad.
min_data_in_leaf → evita overfitting.

07 — Tuning

Optimización de Hiperparámetros

GridSearchCV

Prueba todas las combinaciones. Exhaustivo pero costoso.

Combinaciones = Π len(param_grid[k])
Grid 4×3×3×2 = 72 combinaciones × 5 folds = 360 fits
RandomizedSearchCV

Muestrea n_iter combinaciones al azar. Eficiente con espacios grandes o continuos.

n_iter × cv = total fits
Permite distribuciones: scipy.stats.uniform(0.01, 0.3)
from sklearn.model_selection import RandomizedSearchCV
from scipy.stats import uniform, randint

param_dist = {
    'n_estimators': randint(100, 500),
    'max_depth': randint(2, 8),
    'learning_rate': uniform(0.01, 0.3),
    'subsample': uniform(0.6, 0.4),
    'colsample_bytree': uniform(0.5, 0.5)
}
random_search = RandomizedSearchCV(
    xgb.XGBClassifier(random_state=42),
    param_dist, n_iter=50, cv=5,
    scoring='roc_auc', random_state=42, n_jobs=-1
)
random_search.fit(X_train, y_train)
print(random_search.best_params_)

🏦 Práctica 1: Bank Marketing — Árbol de Decisión

Dataset de campañas de marketing bancario portugués (UCI). Target y: ¿el cliente suscribe un depósito a plazo? Clasificación binaria con clases desbalanceadas (~89% No / ~11% Sí).

ClasificaciónDesbalanceoGridSearchCVBank Marketing UCI
✅
Obligatorio según el enunciado: (1) identificar target y analizar su distribución, (2) grid de hiperparámetros razonado, (3) comparar DT optimizado vs Logistic Regression baseline (sin optimizar), (4) evaluación final contra test.
import pandas as pd
from sklearn.tree import DecisionTreeClassifier
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import train_test_split, GridSearchCV
from sklearn.metrics import classification_report, f1_score

# 1. Carga
df = pd.read_csv('bank.csv', sep=';')
print(df['y'].value_counts(normalize=True))  # distribución del target

# 2. Preprocesamiento
df['y'] = (df['y'] == 'yes').astype(int)
df_enc = pd.get_dummies(df, drop_first=True)
X, y = df_enc.drop('y', axis=1), df_enc['y']

# 3. Split estratificado (obligatorio con desbalanceo)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, stratify=y, random_state=42)

# 4. Baseline: Logistic Regression SIN optimizar
lr = LogisticRegression(max_iter=1000)
lr.fit(X_train, y_train)
print(f"Baseline LR F1: {f1_score(y_test, lr.predict(X_test)):.3f}")

# 5. GridSearch DT
param_grid = {
    'max_depth': [3, 5, 7, 10],
    'min_samples_split': [2, 10, 50],
    'min_samples_leaf': [1, 5, 20],
    'class_weight': [None, 'balanced']
}
grid = GridSearchCV(
    DecisionTreeClassifier(random_state=42),
    param_grid, cv=5, scoring='f1', n_jobs=-1
)
grid.fit(X_train, y_train)
print(grid.best_params_)

# 6. Evaluación final contra test
print(classification_report(y_test, grid.predict(X_test)))

🩺 Práctica 2: Pima Diabetes — Ensembles

Dataset mujeres Pima Indians ≥21 años. Target class: desarrollo de diabetes en 5 años. Construir ≥3 modelos (al menos uno bagging, uno boosting), comparar en CV, elegir el mejor y evaluarlo contra test.

BaggingBoostingComparación CVPima Indians
⚠️
Regla de oro: la comparación entre modelos se hace con cross_val_score sobre train. El test set se toca una sola vez, con el modelo ganador ya optimizado.
import pandas as pd
from sklearn.ensemble import (BaggingClassifier, RandomForestClassifier,
                                 AdaBoostClassifier, GradientBoostingClassifier)
from sklearn.tree import DecisionTreeClassifier
from sklearn.model_selection import train_test_split, cross_val_score, GridSearchCV
from sklearn.metrics import classification_report
import xgboost as xgb

# Carga
url = "https://raw.githubusercontent.com/jbrownlee/Datasets/master/pima-indians-diabetes.data.csv"
names = ['preg','plas','pres','skin','test','mass','pedi','age','class']
df = pd.read_csv(url, names=names)
X, y = df.drop('class', axis=1), df['class']
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.2, stratify=y, random_state=42)

# Los 5 modelos
modelos = {
    'Bagging': BaggingClassifier(
        estimator=DecisionTreeClassifier(max_depth=5),
        n_estimators=100, random_state=42),
    'RandomForest': RandomForestClassifier(
        n_estimators=200, random_state=42),
    'AdaBoost': AdaBoostClassifier(
        n_estimators=200, learning_rate=0.5, random_state=42),
    'GradientBoosting': GradientBoostingClassifier(
        n_estimators=200, learning_rate=0.05,
        max_depth=3, random_state=42),
    'XGBoost': xgb.XGBClassifier(
        n_estimators=200, random_state=42,
        eval_metric='logloss')
}

# Comparar con CV (SIN tocar test)
resultados = {}
for nombre, modelo in modelos.items():
    scores = cross_val_score(modelo, X_train, y_train,
                              cv=5, scoring='roc_auc', n_jobs=-1)
    resultados[nombre] = scores
    print(f"{nombre}: {scores.mean():.3f} ± {scores.std():.3f}")

# Mejor modelo → optimizar → evaluar contra test
mejor_nombre = max(resultados, key=lambda k: resultados[k].mean())
print(f"Mejor modelo: {mejor_nombre}")

# Entrenar en todo train y evaluar en test
mejor = modelos[mejor_nombre]
mejor.fit(X_train, y_train)
print(classification_report(y_test, mejor.predict(X_test)))
