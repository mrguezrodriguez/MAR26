Sprint 14 · Modelos No Supervisados II · Unidad 2

Feature Selection

Seleccionar las variables más relevantes para el modelo: menos ruido, menos overfitting, más velocidad, más interpretabilidad. Tres familias de métodos, cada una con su lógica.

Intro · Análisis Visual

¿Por qué seleccionar features antes de modelar?

Más features no siempre es mejor. Las variables irrelevantes añaden ruido, las redundantes no aportan información nueva, y juntas disparan el tiempo de entrenamiento y la probabilidad de overfitting. Feature Selection es el proceso de quedarse solo con las variables que aportan señal real.

El análisis visual es el primer paso: distribuciones, correlaciones y relación con el target revelan qué features son prometedoras antes de tocar ningún modelo.

Filter independiente

Evalúa cada feature de forma individual usando estadísticas. No entrena ningún modelo. Rápido, pero no captura interacciones entre variables.

Wrapper iterativo

Prueba subconjuntos de features entrenando el modelo real en cada iteración. Captura interacciones, pero computacionalmente costoso.

Embedded integrado

La selección ocurre durante el propio entrenamiento del modelo (Lasso penaliza coeficientes a 0, Random Forest calcula importancias).

Filtrado · Métodos Filter

Filtrar por estadísticas del dato

Los métodos filter no necesitan entrenar ningún modelo. Calculan una puntuación para cada feature individualmente y eliminan las de menor score. Son el primer paso natural antes de cualquier método más costoso.

VarianceThreshold — eliminar constantes

Elimina features cuya varianza es inferior a un umbral. Una feature constante (var = 0) no aporta nada. También útil para casi-constantes. No necesita el target.

Correlación — eliminar redundantes

Si dos features tienen correlación > 0.85–0.95, aportan información casi duplicada. Se queda una y se descarta la otra. Calcular la matriz de correlación y aplicar un umbral manualmente.

SelectKBest / SelectPercentile — con target

Puntúa cada feature contra el target usando un test estadístico. Para clasificación: f_classif (ANOVA F-test) o mutual_info_classif. Para regresión: f_regression o mutual_info_regression.

Chi-cuadrado (χ²) — para categorías

Mide la dependencia entre una feature categórica/discreta y el target de clasificación. Solo válido para features no negativas (frecuencias, counts). Valor alto de χ² → más dependencia → más útil.

from sklearn.feature_selection import VarianceThreshold, SelectKBest from sklearn.feature_selection import f_classif, mutual_info_classif, chi2 # 1. Eliminar features con varianza casi nula sel_var = VarianceThreshold(threshold=0.01) X_var = sel_var.fit_transform(X_train) # 2. Eliminar features muy correlacionadas (manual) import pandas as pd, numpy as np corr_matrix = pd.DataFrame(X_train).corr().abs() upper = corr_matrix.where(np.triu(np.ones(corr_matrix.shape), k=1).astype(bool)) to_drop = [col for col in upper.columns if any(upper[col] > 0.90)] # 3. SelectKBest con F-test (clasificación) selector = SelectKBest(score_func=f_classif, k=10) X_sel = selector.fit_transform(X_train, y_train) # Ver qué features quedaron: selected = X.columns[selector.get_support()] # 4. Información mutua (captura relaciones no lineales) selector_mi = SelectKBest(score_func=mutual_info_classif, k=10) X_mi = selector_mi.fit_transform(X_train, y_train)
💡 f_classif vs mutual_info_classif: f_classif (ANOVA) asume relación lineal entre feature y target. mutual_info captura cualquier dependencia estadística, lineal o no. Con datos no lineales, mutual_info generalmente da mejores resultados pero es más lento.
Selección por Modelo · Embedded

Dejar que el modelo elija

Los métodos embedded integran la selección dentro del propio entrenamiento. El modelo aprende qué variables importan al mismo tiempo que aprende a predecir. Dos enfoques principales: regularización L1 (Lasso) que lleva coeficientes a 0, y feature importance de modelos de árboles.

from sklearn.linear_model import Lasso, LassoCV from sklearn.feature_selection import SelectFromModel from sklearn.ensemble import RandomForestClassifier # ── Lasso: coeficientes → 0 con regularización L1 ── lasso_cv = LassoCV(cv=5, random_state=42) lasso_cv.fit(X_train_scaled, y_train) # Features con coeficiente ≠ 0 sel_lasso = SelectFromModel(lasso_cv, prefit=True) X_lasso = sel_lasso.transform(X_train_scaled) mask = sel_lasso.get_support() print("Features Lasso:", X.columns[mask].tolist()) # ── Feature Importance con Random Forest ── rf = RandomForestClassifier(n_estimators=200, random_state=42) rf.fit(X_train, y_train) importances = pd.Series(rf.feature_importances_, index=X.columns) importances.sort_values(ascending=False).plot(kind='bar') # Seleccionar las k más importantes sel_rf = SelectFromModel(rf, threshold='mean', prefit=True) X_rf = sel_rf.transform(X_train) # ── Permutation Importance (más fiable, evita sesgo cardinal) ── from sklearn.inspection import permutation_importance perm = permutation_importance(rf, X_test, y_test, n_repeats=20) perm_imp = pd.Series(perm.importances_mean, index=X.columns).sort_values(ascending=False)
⚠ Feature importance de árboles puede ser sesgada hacia features con más valores únicos (alta cardinalidad). Si tienes categorías con muchos niveles, usa permutation_importance que es agnóstico al tipo de feature.

Lasso (L1) — coeficientes exactamente 0

La penalización L1 lleva coeficientes a exactamente 0 (a diferencia de Ridge que los encoge pero no los elimina). α es el hiperparámetro: más grande → más features eliminadas. Usar LassoCV para elegir α por CV.

SelectFromModel — interfaz unificada

Funciona con cualquier modelo que tenga coef_ o feature_importances_. El parámetro threshold controla el corte: 'mean', 'median', un float, o '1.25*mean'.

Wrappers · RFE

Evaluar subconjuntos de features

Los wrappers usan el modelo como caja negra para evaluar diferentes subconjuntos de features. El método más popular es RFE (Recursive Feature Elimination): entrena el modelo con todas las features, elimina la menos importante, y repite hasta quedarse con el número deseado.

from sklearn.feature_selection import RFE, RFECV from sklearn.svm import SVC from sklearn.ensemble import GradientBoostingClassifier # ── RFE: elegir k features manualmente ── estimator = GradientBoostingClassifier(n_estimators=100, random_state=42) rfe = RFE(estimator=estimator, n_features_to_select=8, step=1) rfe.fit(X_train, y_train) print("Ranking de features:") ranking = pd.Series(rfe.ranking_, index=X.columns).sort_values() print(ranking) # 1 = seleccionada X_rfe = rfe.transform(X_train) # ── RFECV: k elegido automáticamente por CV ── rfecv = RFECV( estimator = GradientBoostingClassifier(n_estimators=100), step = 1, cv = 5, scoring = 'f1_macro', min_features_to_select = 3 ) rfecv.fit(X_train, y_train) print(f"Nº óptimo de features: {rfecv.n_features_}") print("Features seleccionadas:", X.columns[rfecv.support_].tolist()) # Plot CV score vs nº de features import matplotlib.pyplot as plt plt.plot(range(1, len(rfecv.cv_results_['mean_test_score'])+1), rfecv.cv_results_['mean_test_score']) plt.xlabel('Nº de features'); plt.ylabel('CV score F1')
⚠ RFE es costoso: entrena el modelo tantas veces como features tenga el dataset (o más, con step=1). Sobre datasets grandes, usa step > 1 para eliminar varias features por iteración, o usa primero un Filter para reducir el espacio de búsqueda.
No Supervisados · Sin target

Feature Selection sin etiquetas

Cuando no tienes target (clustering, detección de anomalías, compresión), no puedes usar f_classif ni mutual_info con y. Las opciones son: eliminar por varianza, por correlación, o usar PCA/Autoencoder para proyectar a un espacio de menor dimensión.

from sklearn.feature_selection import VarianceThreshold import pandas as pd, numpy as np # 1. VarianceThreshold (no necesita y) sel = VarianceThreshold(threshold=0.05) X_filtered = sel.fit_transform(X) print(f"Features antes: {X.shape[1]}, después: {X_filtered.shape[1]}") # 2. Pipeline · Sklearn

Feature Selection dentro de un Pipeline

Lo más importante: la selección de features debe entrar dentro del Pipeline de sklearn. Si la haces fuera, contaminas el test set con información del train (data leakage).

from sklearn.pipeline import Pipeline from sklearn.preprocessing import StandardScaler from sklearn.feature_selection import SelectKBest, f_classif, RFECV from sklearn.ensemble import RandomForestClassifier, GradientBoostingClassifier from sklearn.model_selection import cross_val_score, GridSearchCV # ── Pipeline correcto (sin leakage) ── pipe = Pipeline([ ('scaler', StandardScaler()), ('selector', SelectKBest(score_func=f_classif)), ('model', RandomForestClassifier(n_estimators=200, random_state=42)) ]) # Buscar k óptimo por GridSearch param_grid = {'selector__k': [5, 8, 10, 15, 'all']} gs = GridSearchCV(pipe, param_grid, cv=5, scoring='f1_macro', n_jobs=-1) gs.fit(X_train, y_train) print("Mejor k:", gs.best_params_['selector__k']) print("Mejor CV score:", gs.best_score_.round(3)) print("Test score:", gs.score(X_test, y_test).round(3)) # ── Encadenar métodos (Filter → Embedded) ── from sklearn.linear_model import LogisticRegression pipe2 = Pipeline([ ('scaler', StandardScaler()), ('var', VarianceThreshold(threshold=0.01)), # paso 1: quita constantes ('selector', SelectKBest(f_classif, k=20)), # paso 2: top-20 por F-test ('model', LogisticRegression(C=1.0, max_iter=1000)) ])
💡 Orden recomendado en la práctica: 1. VarianceThreshold → elimina constantes y casi-constantes 2. Eliminar correlación alta (manual con heatmap) 3. SelectKBest / mutual_info → reducción rápida basada en target 4. RFE o SelectFromModel → refinamiento final con el modelo real 5. Todo dentro de un Pipeline para evitar data leakage
