Concepto base

¿Qué es el aprendizaje supervisado?

En el aprendizaje supervisado, el modelo aprende a partir de ejemplos etiquetados: datos de entrada (features) con su respuesta correcta conocida (target). El objetivo es que, una vez entrenado, sea capaz de predecir el target para datos nuevos que nunca ha visto.

Regresión
Predice un número continuo
El target es un valor real. Ejemplos: precio de una casa, temperatura de mañana, salario esperado. El error se mide con MSE, RMSE o R².
Clasificación
Predice una categoría
El target es una clase discreta. Ejemplos: spam/no spam, diagnóstico médico, dígito 0–9. El error se mide con accuracy, F1, AUC-ROC.
Flujo siempre igual
Datos etiquetados → EDA y selección de features → entrenamiento → evaluación → predicción en datos nuevos. Todos los modelos de esta guía siguen este flujo.
Modelo 01

Regresión Lineal

El modelo más simple del aprendizaje supervisado. Asume que existe una relación lineal entre las features y el target: si subes una variable, el target sube o baja proporcionalmente. A pesar de su simplicidad, es la base matemática de casi todo lo demás.

Regresión Lineal
Regresión Paramétrico
Cómo funciona
Busca los coeficientes β₀, β₁… βₙ que mejor ajustan una recta (o hiperplano) a los datos. Lo hace minimizando la suma de los errores al cuadrado entre lo que predice y lo que es real.
ŷ = β₀ + β₁x₁ + β₂x₂ + … + βₙxₙ
Cuándo usarlo
Cuando la relación entre variables y target es aproximadamente lineal. Útil como primera aproximación. Muy interpretable: el coeficiente β₁ dice cuánto cambia y por cada unidad de x₁.
Regularización: si el modelo sobreajusta (memoriza el train y falla en test), se añade una penalización. Ridge (L2) encoge coeficientes. Lasso (L1) puede llevarlos a cero eliminando features. ElasticNet combina ambas.
Modelo 02

Regresión Logística

A pesar del nombre, es un modelo de clasificación. Toma la salida lineal de la regresión y la aplasta con la función sigmoide para que el resultado sea una probabilidad entre 0 y 1. Con un umbral de decisión (por defecto 0.5) convierte esa probabilidad en una clase.

Regresión Logística
Clasificación Binaria / Multiclase
La clave: función sigmoide
La función sigmoide toma cualquier número real y lo comprime al rango (0, 1). El resultado se interpreta como la probabilidad de pertenecer a la clase positiva.
P(y=1) = 1 / (1 + e^−z)
donde z = β₀ + β₁x₁ + … + βₙxₙ
Cuándo usarlo
Clasificación binaria (sí/no) o multiclase con OvR o Softmax. Muy interpretable: los coeficientes indican la dirección e importancia de cada feature. Buen punto de partida antes de probar modelos más complejos.
Métricas clave: en clasificación ya no usas R² ni RMSE. Usas accuracy (% de aciertos), precision y recall (cuando las clases están desbalanceadas), F1 (media armónica de ambas) y AUC-ROC (qué tan bien separa las clases para cualquier umbral).
Modelo 03

Árboles de decisión

Un árbol de decisión aprende haciendo preguntas sobre las features, como un diagrama de flujo. Cada nodo es una pregunta (¿edad > 30?), cada rama es una respuesta, y cada hoja es una predicción. Son muy fáciles de interpretar y no requieren escalar los datos.

Árbol de decisión
Regresión Clasificación Interpretable
Cómo aprende
En cada nodo elige la feature y el umbral que mejor divide los datos, maximizando la "pureza" de cada subgrupo. Para clasificación usa Gini o Entropía. Para regresión minimiza la varianza.
Gini = 1 − Σ pᵢ²
Ventajas y límites
Muy interpretable, no necesita escalar datos, maneja bien variables mixtas. El gran problema es el overfitting: un árbol sin límite memoriza el training set. Se controla con max_depth, min_samples_leaf, etc.
Por qué son importantes: los árboles de decisión son los bloques de construcción de Random Forest y Boosting. Entender cómo funciona un árbol es entender la base de los modelos más potentes del sector.
Modelo 04 · Ensamblado

Random Forest

Random Forest es el primer modelo de ensamblado que estudiarás. La idea es simple y brillante: en lugar de confiar en un solo árbol (que puede equivocarse o sobreajustar), entrenas cientos de árboles distintos y dejas que voten. El resultado es mucho más robusto.

Random Forest
Regresión Clasificación Bagging
Cómo funciona (Bagging)
Crea N árboles entrenados sobre muestras aleatorias distintas del dataset (bootstrap). Además, cada árbol solo ve un subconjunto aleatorio de las features en cada nodo. Esto hace que los árboles sean distintos entre sí y que sus errores se cancelen.
Predicción final
Clasificación: voto mayoritario de todos los árboles. Regresión: media de las predicciones de todos los árboles. El resultado suele ser mucho más estable y preciso que cualquier árbol individual.
ŷ = mean(árbol₁, árbol₂, …, árbolₙ)
Ventaja clave: el overfitting desaparece casi por completo. Al promediar muchos árboles, los errores individuales se cancelan. Además ofrece feature importance: sabe decirte qué variables fueron más útiles para predecir.
Modelo 05 · Ensamblado

Boosting: GBT, XGBoost, LightGBM, CatBoost

Boosting es otra estrategia de ensamblado, pero con una filosofía diferente a Random Forest. En lugar de entrenar árboles independientes en paralelo, los entrena en secuencia: cada árbol nuevo se enfoca en corregir los errores del anterior. El resultado son los modelos con mejor rendimiento en tabular data en la práctica.

Gradient Boosting (GBT)
Regresión Clasificación Secuencial
Cómo funciona
Empieza con una predicción base (la media del target). El árbol 1 aprende a predecir los residuos (errores). El árbol 2 aprende los residuos del árbol 1. Y así N veces. La suma de todos los árboles es la predicción final.
ŷ = árbol₁ + η·árbol₂ + η·árbol₃ + …
η = learning rate (controla el paso)
Variantes y cuándo usarlas
XGBoost: añade regularización y es muy rápido. Estándar en competiciones Kaggle.
LightGBM: más eficiente en memoria, ideal con datasets grandes.
CatBoost: maneja variables categóricas directamente sin encoding previo.
Random Forest vs Boosting: RF entrena árboles en paralelo, independientes, para reducir varianza. Boosting los entrena en serie, cada uno aprendiendo del error anterior, para reducir sesgo. Boosting suele ganar en precisión, pero es más sensible al overfitting si no se ajusta bien el learning rate y el número de árboles.
Modelo 06

Support Vector Machine (SVM)

SVM busca el hiperplano que separa las clases con el mayor margen posible. En lugar de intentar clasificar bien todos los puntos, se centra en los más difíciles: los que están en el borde de cada clase, llamados vectores de soporte. Con el "kernel trick" puede resolver problemas no lineales.

Support Vector Machine
Clasificación Regresión (SVR) Margen máximo
Cómo funciona
Encuentra el hiperplano de separación que maximiza la distancia (margen) entre las dos clases. Los puntos más cercanos al hiperplano se llaman vectores de soporte y son los que definen la frontera.
maximizar: 2 / ‖w‖
Kernel trick
Cuando los datos no son separables linealmente, SVM los proyecta a un espacio de mayor dimensión donde sí lo son. Los kernels más comunes: lineal, polinomial y RBF (gaussiano). Permite resolver problemas muy complejos.
Cuándo brilla SVM: con datasets pequeños y de alta dimensionalidad (muchas features, pocos datos). En datasets grandes es lento. Necesita que los datos estén escalados (StandardScaler o similar). El hiperparámetro C controla el trade-off entre margen y errores permitidos.
Modelo 07

K-Nearest Neighbors (K-NN)

K-NN es el modelo más intuitivo de todos: para predecir un punto nuevo, busca los K puntos más cercanos en el dataset de entrenamiento y decide por mayoría (clasificación) o por media (regresión). No aprende nada durante el entrenamiento, simplemente memoriza los datos.

K-Nearest Neighbors
Clasificación Regresión Lazy learning
Cómo funciona
Dado un punto nuevo, calcula su distancia a todos los puntos del dataset. Toma los K más cercanos. Si es clasificación, devuelve la clase mayoritaria entre ellos. Si es regresión, devuelve la media de sus valores.
distancia Euclídea: √Σ(xᵢ − yᵢ)²
El valor de K importa mucho
K=1: el modelo memoriza el training set, overfitting total. K muy grande: fronteras demasiado suavizadas, underfitting. El K óptimo se busca con validación cruzada. Los datos deben estar escalados obligatoriamente.
Limitación importante: K-NN es muy lento con datasets grandes porque calcula distancias a todos los puntos para cada predicción. No tiene ningún modelo interno que aprender: todo el trabajo lo hace en la predicción. Por eso se llama "lazy learning" (aprendizaje perezoso).
Resumen

¿Cuándo usar cada modelo?

No existe un modelo universalmente mejor. La elección depende del tamaño del dataset, la interpretabilidad que necesites, si es regresión o clasificación y cuánto tiempo tienes para ajustar hiperparámetros.

Regla práctica: empieza siempre con el modelo más simple que tenga sentido para el problema (Regresión Lineal/Logística). Si no es suficiente, prueba Random Forest. Si necesitas exprimir al máximo el rendimiento, prueba XGBoost o LightGBM. SVM y K-NN tienen nichos específicos donde destacan.
