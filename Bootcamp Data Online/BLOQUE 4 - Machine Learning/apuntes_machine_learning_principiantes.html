Guía de Machine Learning para Entender los Conceptos Fundamentales

1. ¿Qué es Machine Learning?

La idea básica es muy simple:

Queremos que un programa encuentre patrones en datos para poder hacer predicciones.

2. Conceptos básicos

ConceptoSignificado sencillo
FeatureInformación de entrada (edad, altura, metros cuadrados, etc.)
TargetLo que queremos predecir
DatasetConjunto de datos completo
SampleUna fila del dataset
ModeloLa regla matemática que aprende la máquina

3. Ejemplo de regresión lineal

Queremos predecir el precio de una casa.

Precio = β0 + β1·(metros cuadrados)
  • β0 = punto de partida.
  • β1 = cuánto cambia el precio por cada metro cuadrado adicional.

4. ¿Qué son β0 y β1?

Imagina:

Precio = 50000 + 1000·m²
  • β0 = 50000 → precio base.
  • β1 = 1000 → cada metro cuadrado añade 1000 €.
β0 = dónde empiezas.
β1 = cuánto cambia la predicción cuando cambia una variable.

Durante el entrenamiento sí conocemos las respuestas correctas.

6. ¿Qué es una predicción?

Sale de la fórmula del modelo.

Y = 1 + 2X

Si X=3:

Predicción = 1 + 2·3 = 7

7. ¿Qué es el error?

La diferencia entre la realidad y la predicción.

Valor real = 10
Predicción = 7

Error = 3

8. Error Cuadrático Medio (MSE)

Mide cuánto se equivoca el modelo de media.

RealPredicciónError
1082
2025-5
30282

Errores al cuadrado:

2² = 4
(-5)² = 25
2² = 4

MSE:

(4 + 25 + 4) / 3 = 11
Cuanto menor sea el MSE, mejor está prediciendo el modelo.

9. ¿Qué es Gradient Descent?

Es el mecanismo que corrige los coeficientes del modelo para reducir el error.

Imagina que estás bajando una montaña con niebla:

Mides la pendiente
↓
Avanzas cuesta abajo
↓
Mides otra vez
↓
Repites

Gradient Descent hace exactamente eso con el error.

10. ¿Qué es el gradiente?

El gradiente indica hacia qué dirección hay que mover los parámetros para reducir el error.

No es más que una brújula matemática.

11. SGD (Stochastic Gradient Descent)

Hay dos formas de actualizar parámetros:

Gradient Descent clásico

Usa todos los datos
↓
Calcula error
↓
Actualiza parámetros

SGD

Usa un ejemplo
↓
Actualiza parámetros
↓
Usa otro ejemplo
↓
Actualiza parámetros

SGD suele ser más rápido con datasets grandes.

12. Train vs Test

Train

Conozco X e Y
↓
Aprendo los parámetros

Test

Conozco X e Y
↓
NO aprendo
↓
Solo evalúo
El conjunto de test sirve para comprobar si el modelo realmente ha aprendido o simplemente ha memorizado.

13. Overfitting

Cuando el modelo memoriza los datos de entrenamiento.

Error train = muy bajo
Error test = muy alto

Eso significa que generaliza mal.

14. ¿Cómo elegir un algoritmo?

Si predices números

  • Linear Regression
  • Random Forest Regressor
  • XGBoost Regressor

Si predices categorías

  • Logistic Regression
  • Random Forest Classifier
  • XGBoost Classifier

16. Flujo completo de un proyecto

1. Entender el problema
2. Elegir target
3. Preparar datos
4. Separar train/test
5. Entrenar modelo
6. Medir error
7. Comparar modelos
8. Elegir el mejor
9. Hacer predicciones reales

Resumen para memorizar

Features → Modelo → Predicción → Error → Ajuste de parámetros → Modelo mejorado
Train = aprender.
Test = evaluar.
Producción = predecir.
